# UI 용어 24 — 화면 요소를 이름으로 부르는 사전

- 출처: 코드깎는노인 「바이브코더가 반드시 알아야 할 필수 용어 24가지」 https://youtu.be/mlhKEy-2bgI (2026-10-25 게시). 영상 화면은 옮기지 않고 우리 표로 다시 정리했다. 요청 문장은 영상의 예문을 따랐다(자동 자막 오인식만 바로잡음).
- 쓰는 곳: 화면 명세(`02-screens`)와 화면 수정 요청에서 「예쁘게·세련되게」 대신 이 이름을 쓴다 — 무엇을 어디에 어떻게 둘지가 한 번에 전해져 주고받는 횟수가 준다.

## 쓰는 법 — 요청 공식
**UI 용어 + 원하는 동작 + 적용 조건** (영상 9:48~11:06)
- 예: 「설정 버튼을 누르면(조건) 오른쪽에서(동작) 드로어가(용어) 열리고, 바깥 클릭과 ESC 로 닫히게(조건) 해 줘.」
- 나쁜 예 → 좋은 예: 「세련된 웹사이트 · 카드 예쁘게 · 스크롤 효과」 → 「첫 화면은 히어로 섹션, 핵심 기능은 벤토 그리드, 상단은 스티키 헤더, 설정은 오른쪽 드로어 · 카드는 가벼운 호버 + 스크롤 리빌 + 0.1초 간격 스태거」

## 1부 레이아웃 7
| 용어 | 뜻 | 요청 문장 |
|---|---|---|
| Hero Section 히어로 섹션 | 첫 화면의 대표 영역(CTA = 눌러 주길 바라는 핵심 버튼) | 첫 화면에 짧고 강한 제목과 설명, CTA 버튼, 제품 이미지를 넣은 히어로 섹션을 만들어 줘. |
| Responsive Layout 반응형 레이아웃 | 화면 폭에 맞춘 배치 | 반응형 레이아웃으로 데스크톱은 3열, 태블릿은 2열, 모바일은 1열로 카드가 재배치되게 해 줘. |
| Card Layout 카드 레이아웃 | 정보를 독립된 박스로 나누기 | 서비스 기능을 카드 레이아웃으로 정리하고 각 카드에는 아이콘과 제목, 짧은 설명을 넣어 줘. |
| Bento Grid 벤토 그리드 | 크기 다른 카드 격자(도시락) | 핵심 기능은 큰 카드로, 나머지는 작은 카드로 구성한 벤토 그리드 섹션을 만들어 줘. 모바일에서는 한 열로 정렬해 줘. |
| Sidebar Layout 사이드바 레이아웃 | 옆에 고정된 메뉴 + 오른쪽 작업 공간 | 왼쪽에 고정된 사이드바 내비게이션, 오른쪽에 메인 콘텐츠가 있는 대시보드 레이아웃을 만들어 줘. |
| Sticky Header 스티키 헤더 | 스크롤해도 위에 붙어 있는 헤더 | 상단 내비게이션을 스티키 헤더로 만들고 스크롤 중에도 보이게 해 줘. |
| Split Layout 스플릿 레이아웃 | 좌우 분할 배치 | 데스크톱에서는 이미지와 설명을 좌우 50:50 스플릿 레이아웃으로 배치하고 모바일에서는 세로로 쌓아 줘. |

## 2부 UI 컴포넌트 9
| 용어 | 뜻 | 요청 문장 |
|---|---|---|
| Tabs 탭 | 같은 자리에서 내용 전환(옆으로) | 개요, 기능, 요금 정보를 탭 컴포넌트로 구성하고 선택된 탭을 강조해 줘. |
| Accordion 아코디언 | 펼치고 접는 목록(아래로) | FAQ를 아코디언으로 만들어 줘. 질문을 누르면 답변이 펼쳐지고 다시 누르면 접히게 해 줘. |
| Modal / Dialog 모달·다이얼로그 | 화면 위 확인 창(뒤를 덮는 막 = 오버레이·백드롭) | 삭제 버튼을 누르면 확인 모달을 띄우고 취소 버튼이나 ESC 로 닫히게 해 줘. |
| Drawer 드로어 | 옆에서 서랍처럼 열리는 패널(하던 일을 덜 끊음) | 설정 버튼을 누르면 오른쪽에서 드로어가 열리게 하고 바깥 영역 클릭과 ESC 로 닫히게 해 줘. |
| Dropdown 드롭다운 | 버튼 아래로 펼치는 선택 목록 | 정렬 버튼을 누르면 최신순, 인기순, 이름순을 고르는 드롭다운 메뉴가 나오게 해 줘. |
| Tooltip 툴팁 | 작은 설명 말풍선 | 설정 항목 옆에 도움말 아이콘을 넣고 마우스를 올리거나 키보드로 포커스하면 툴팁이 보이게 해 줘. |
| Toast / Snackbar 토스트·스낵바 | 잠깐 떴다 사라지는 알림 | 저장이 성공하면 화면 하단에 「저장되었습니다」 토스트 알림을 3초간 보여 줘. |
| Carousel 캐러셀 | 옆으로 넘기는 카드(회전목마) | 고객 후기를 캐러셀로 만들어 줘. 좌우 버튼과 모바일 스와이프로 넘길 수 있게 해 줘. |
| Skeleton Loading 스켈레톤 로딩 | 불러오는 동안 회색 윤곽 먼저 | 데이터를 불러오는 동안 실제 카드 구조와 비슷한 스켈레톤 로딩 UI 를 보여 줘. |

## 3부 효과·인터랙션 8
| 용어 | 뜻 | 요청 문장 |
|---|---|---|
| Hover Effect 호버 이펙트 | 마우스를 올리면 반응(누를 수 있음을 알림) | 카드에 호버 이펙트를 넣고 마우스를 올리면 그림자가 조금 진해지면서 카드가 살짝 위로 올라가게 해 줘. |
| Scroll Reveal 스크롤 리빌 | 스크롤해 보이는 순간 등장 | 각 기능 섹션이 화면에 들어오면 아래에서 살짝 올라오면서 나타나는 스크롤 리빌을 적용해 줘. |
| Stagger Animation 스태거 애니메이션 | 시간차로 차례 등장 | 카드 목록이 처음 나타날 때 각 카드가 0.1초 간격으로 차례로 등장하는 스태거 애니메이션을 넣어 줘. |
| Smooth Transition 스무스 트랜지션 | 상태가 부드럽게 바뀜 | 버튼과 카드의 호버·선택 상태가 0.2초(200ms) 정도의 부드러운 트랜지션으로 바뀌게 해 줘. |
| Glassmorphism 글래스모피즘 | 반투명 유리 질감(글자 대비 주의) | 카드에 반투명 배경과 백드롭 블러를 적용한 글래스모피즘 스타일을 쓰고 텍스트 대비는 유지해 줘. |
| Parallax Scrolling 패럴랙스 스크롤링 | 앞뒤 속도 차로 깊이감(약하게) | 히어로 섹션의 배경 장식에 약한 패럴랙스 스크롤링을 넣고 모바일과 모션 감소 설정에서는 효과를 줄여 줘. |
| Scroll Snap 스크롤 스냅 | 섹션 단위로 착 정렬 | 전체 화면으로 구성한 소개 섹션에 스크롤 스냅을 적용해서 스크롤할 때 각 섹션에 자연스럽게 정렬되게 해 줘. |
| Micro-interaction 마이크로 인터랙션 | 작은 행동에 바로 돌아오는 시각 반응 | 저장 버튼을 누르면 로딩 상태를 거쳐 체크 아이콘으로 바뀌는 짧은 마이크로 인터랙션을 만들어 줘. |

## 함께 지킬 것
- 어르신·초보 대상 화면: 3부 효과는 약하게 하고 기기의 「동작 줄이기(모션 감소)」 설정을 따른다. 글래스모피즘은 글자 대비가 모자라기 쉽다 — 글자 크기·대비 기준이 우선이다.
- 모바일은 축소판이 아니라 따로 설계한다 — 「반응형 레이아웃」 문장을 쓸 때도 모바일 배치를 따로 적는다.
