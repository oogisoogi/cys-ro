# computer-control — 컴퓨터 통제권 넘기기 (본부 마스터 전용)

도구: `C="${CYS_PACK_DIR:-$HOME/.cys/pack}/bin/javis_computer_control.py"` · 설계 정본 = 팩 `docs/DESIGN-cu-1111.md`.
해석기는 dept-by-chat 과 같게 잡는다(맨 `python3` 금지 — 개발자 도구 없는 맥에서는 설치 창만 뜬다):
`. "${CYS_PACK_DIR:-$HOME/.cys/pack}/hooks/_lib.sh" 2>/dev/null && cys_resolve_py 2>/dev/null; PY="${CYS_PY:-python3}"`
모든 명령은 stdout 에 JSON 한 줄을 낸다. **`say` 를 한 글자도 바꾸지 말고 그대로 사용자에게 말한다**(거부 `"ok": false` 도 같다).
명령은 **지금 대화하는 칸의 폴더에서** 부른다(화면 조작 켜짐 기록이 폴더마다라서 — `cd` 하지 않는다).

## 언제
- 사용자가 컴퓨터에서 마스터가 맡을 수 있는 것을 찾거나, 맡기거나, 그만 맡기거나, 지금 무엇을 맡고 있는지 물을 때.
- 크롬·카톡·한글 등을 다뤄 달라고 했는데 권한·연결이 안 돼 있을 때(먼저 `scan` 으로 무엇이 빠졌는지 본다).

## 기본 = 마스터가 먼저 정하고 보고(박사님 10-26 21:5x 「우리 선례를 1.1.11에 적용하여 컴퓨터 유즈 자동화 기능을 보완하자」)
- 「내 컴퓨터에서 네가 맡을 수 있는 걸 찾아(맡아) 줘」 → **묻지 않고** `"$PY" "$C" adopt` → `say` 그대로. 지금 바로 맡을 수 있는 칸은
  장부에 올리고 「이렇게 했습니다 · 다르면 말씀」으로 보고한다. `next_action` 이 `chrome-enable` 이면 이어서 그것을 부른다.
- 손 칸은 adopt 가 이름만 알린다 — 사용자가 원하면 아래 3번(guide). 「X 는 빼」 → `revoke <ID>`(상시 기록 — adopt 가 다시 가져오지 않는다).
- 번호 목록을 보고 고르고 싶다고 하면 아래 순서(scan → grant)를 쓴다. 사용자가 고르면 전의 「빼라」 기록은 풀린다.

## 선례 판단 — 사용자에게 묻기 전에 반드시 `decide`
로그인·「허용」, 자료 바깥 보내기, 결제·서명·가입, 앱 닫기, 화면 조작, 설정 바꾸기, 앱 보안 창, 처음 보는 업데이트 창처럼
「물어야 하나?」 싶은 일이 생기면 묻기 전에 `"$PY" "$C" decide <유형> --subject "<대상>" [--in-use yes|no] [--what "<한 일 한 줄>"] [--condition-met yes|no]`.
- `decision: do` → 묻지 않고 하고, 끝나면 `report` 를 그대로 말한다(「이렇게 했습니다 … 다르게 원하시면 말씀해 주세요」).
- `decision: ask` → `ask` 를 그대로 묻고, 답 원문을 파일로 쓴 뒤 `"$PY" "$C" remember <유형> --subject "<대상>" --answer-file <파일> --meaning allow|deny|conditional [--condition "<사용자가 한 말 그대로>"]`.
  답은 상시 기록이다 — **같은 항목을 다시 묻지 않는다**(`already_decided` 가 나오면 그 결정을 따른다 · 사용자가 스스로 바꾼 때만 `--user-changed`).
  조건부 허락은 사용자가 한 말을 **그대로** `--condition` 에 적는다 — 낱말 목록·문법으로 바꾸지 않는다(도구는 조건의 뜻을 해석하지 않는다 · D16). 원문은 이 컴퓨터의 기록 파일에만 남고 원장에는 해시만 간다(2,000자 이하 · 넘으면 자르지 않고 `condition_too_long`).
- `decision: check` → 전에 사용자가 **조건을 붙여** 허락한 것이다 — `condition`(사용자가 한 말 원문)을 읽고 이번 건이 그 조건에 맞는지 **네가 말뜻으로** 판단한다. 맞으면 `--condition-met yes`(= do) · 맞지 않으면 `no`(= 이번만 묻기) · 애매할 때만 사용자에게 한 번 묻는다. 확인 없이 하지 않는다. 조건 원문은 판단에만 쓰고 보고·다른 좌석·외부로 옮기지 않는다.
- `decision: each` 에 `supplement: true` 가 붙으면 옛 판이 조건 끝을 잘라 둔 기록이다 — `ask` 대로 묻고, 사용자가 다시 말한 조건을 `remember … --meaning conditional --condition "<그 말>"` 로 적는다(이 기록만은 `--user-changed` 없이 덮인다 · 그 뒤로 다시 묻지 않는다).
- `decision: each` → 그 건만 `ask` 대로 묻는다(결제·서명 제출·새 가입·비밀번호/2단계/생체 입력·주인 이름으로 남에게 보내기·약관이 자동화를 금지한 서비스 · 기록하지 않는다).
- `decision: never` → `say` 대로 하지 않는다(일부러 막힌 창 · 원격 명령 통로·자격증명 대행·백신 우회).
- 유형: `login` `credential_input` `payment` `sign_submit` `signup` `send_as_owner` `external_send` `settings_change` `app_quit`
  `app_force_quit` `screen_op` `app_security_dialog` `kakao_login` `terms_risk` `update_dialog` `blocked` `install_boundary` — 목록에 없는 새 유형은 `ask`.
- 「이미 쓰는 서비스인가」는 도구가 커넥터 이름·설치 앱(마지막 사용일)으로 본다. 작업 중 이미 로그인된 화면을 직접 봤으면 `--in-use yes`.

## 순서(번호 목록으로 고를 때)
1. `"$PY" "$C" scan` → `say` 그대로(세 칸: 바로 가능 / 내 손 한 번 필요 / 지금은 안 됨 · 번호 목록). 출력의 `scan_id` 를 기억한다.
2. 사용자가 번호를 고르면 답 원문을 **한 글자도 바꾸지 말고** 임시 파일에 쓰고(Write)
   `"$PY" "$C" grant --scan <사용자에게 보인 목록의 scan_id> --pick <번호들 예: 1,3> --answer-file <답 파일>` → `say` 그대로.
   - `reason: scan_replaced` 면 그 사이 목록이 바뀐 것이다 — `scan` 을 다시 보여 주고 다시 고르게 한다(옛 번호로 넘기지 않는다).
   - 「다 해 줘」는 **방금 보인 목록의** 바로·손 칸 번호 전부로 풀어 넘긴다(안 됨 칸 제외) — 목록에 없던 것을 넣지 않는다.
   - 고르지 않은 것은 넘겨받지 않는다. 기본값으로 전부 넘기지 않는다. 뜻이 애매하면 한 번만 묻는다.
   - 사용자가 폴더를 말하면 `--folder <경로>` 를 붙인다.
3. 손 칸 안내: `grant` 의 `say` 가 1단계를 말한다. 사용자가 「다음」이면 `"$PY" "$C" guide <ID> --step <n>` → `say` 그대로.
   「했어」면 `"$PY" "$C" recheck <ID>` → `say` 그대로(됐으면 「이제 제가 맡습니다」, 아니면 빠진 단계만 다시).
4. 그만 맡기라면 `"$PY" "$C" revoke <ID>` → `say` 그대로(맥 권한처럼 마스터가 끌 수 없는 것은 끄는 곳을 안내한다).
5. 「지금 뭘 맡고 있어?」 → `"$PY" "$C" status` → `say` 그대로.

## 크롬 — 마스터가 직접 켠다(박사님 10-26 「/chrome 실행, 크롬 껐다켜기 같은 작업을 주인에게 시키지 말라」)
- `grant` 출력의 `next_action` 이 `chrome-enable` 이면(또는 크롬 도구가 「not connected」·도구 없음이면) 묻지 않고
  `"$PY" "$C" chrome-enable` → `say` 그대로. 도구가 ① 좌석 설정의 크롬 기본 켜기(한 키) ② 연결 파일 ③ 필요할 때만 크롬 다시 켜기
  (사용자 손이 20초 쉴 때 · 화면 알림 1줄 · 정상 종료 · 탭 복원) ④ 이 대화가 끝난 뒤 cysr 재시작 예약(대화는 이어짐)을 한다.
- `pending` 에 `nmh`·`chrome_restart` 가 있으면 사용자가 키보드·마우스를 쓰는 중이었다는 뜻이다 — 다음 턴에 `chrome-enable` 을 한 번 더 부른다(미룬 크롬·좌석 재시작을 도구가 기억하고 이어서 한다).
- 재시작은 이 좌석의 턴이 끝난(화면이 20초 조용한) 뒤에 일어난다 — `chrome-enable` 뒤에는 할 일을 더 시작하지 말고 턴을 끝낸다.
- 사용자가 「크롬 연결도 꺼 줘」·「되돌려 줘」 → `"$PY" "$C" chrome-disable [--seat-restart auto]` → `say` 그대로(켤 때의 원래 값으로).
- 확장이 없거나 꺼져 있으면(웹 스토어 「추가」·확장 로그인) 그것만 사용자 손이다 — `guide chrome`.

## 설정 화면·요청 창 (맥)
- 사용자가 「설정 화면 열어 줘」라고 하면 `"$PY" "$C" open-settings accessibility|screen|automation` → `say` 그대로.
- 손쉬운 사용·화면 기록 목록에 cysr 이 아예 없을 때는 「맥의 요청 창을 띄워 드릴까요? 창의 단추는 직접 누르셔야 합니다」라고
  **먼저 묻고**, 답 원문을 파일로 쓰고 답의 뜻을 판단해 `"$PY" "$C" request-prompt ax|sc --answer-file <답 파일> --meaning yes|no|unclear`.
  `yes` 가 아니면 도구가 띄우지 않는다. 묻지 않고 띄우지 않는다.

## 넘긴 뒤의 규칙
- 크롬 확장 도구·화면 조작·커넥터·앱 자동화·폴더는 **장부(`status`)에 「맡는 중」인 것만** 쓴다. 장부 밖의 것이 필요하면
  쓰기 전에 사용자에게 「이것도 맡겨 주시겠어요?」라고 묻고 위 순서를 탄다.
- 화면 조작으로 카톡은 **보이는 만큼 읽고 직접 보내는 것까지**만 한다(대량 자동 발송 금지). 맥 한글은 화면 조작만.
- 화면 조작은 브라우저를 「보기만」 한다 — 웹 일은 크롬 확장이나 커넥터로 한다.
- 화면 조작 도구가 「권한을 Claude desktop app 에 주라」고 말해도 **cysr 안에서는 cysr 스위치**다(1.1.11 실측 — 도구가 cysr 을
  터미널로 못 알아봐 생기는 오안내). 사용자에게는 「시스템 설정에서 cysr 을 켜 주세요」로 바꿔 말하고 `guide screen` 을 쓴다.

## 하지 않는 것(경계)
- 비밀번호·인증 코드를 받거나 저장하거나 대신 넣지 않는다. 암호 창은 「이 맥에 로그인할 때 쓰는 암호를 직접 넣으세요」라고 안내만.
- 맥 권한 창·크롬 확인 창의 단추를 대신 누르지 않는다. `/mcp`(computer-use) 토글은 사용자가 한다(크롬 기본 켜기는 위 `chrome-enable`).
- 크롬을 강제로 끄지 않는다(도구는 정상 종료만 하고, 안 닫히면 그대로 둔다).
- 백신·보안 설정(윈도우 SmartScreen·사용자 계정 컨트롤 포함)을 우회하라고 하지 않는다.
- 분석 결과로 메일 본문·파일 내용을 열거나 보내지 않는다(도구는 「무엇이 있고 연결됐는가」만 본다).
- `say` 에 없는 약속(시간·결과)을 덧붙이지 않는다.

## 도구가 실패하면
- `"ok": false` 이고 `reason` 이 `internal:…` 이면 `say` 대로 「처음 한 번 준비」 안내 페이지를 함께 열어 보며 확인하자고 한다.
- `reason: no_scan`·`stale_scan` 이면 `scan` 부터 다시.

## 예시 대화
- 사용자: 내 컴퓨터에서 네가 맡을 수 있는 걸 찾아 줘.
- 마스터: (`scan`) → 「이 컴퓨터에서 제가 맡을 수 있는 것을 살펴봤습니다 … ■ 바로 가능 1. 크롬으로 웹 일 … ■ 내 손 한 번 필요 4. 데스크톱 앱 화면 조작 … 맡기실 번호를 말씀해 주세요.」 그대로.
- 사용자: 1번이랑 4번.
- 마스터: (답 원문 파일 → `grant --scan <scan_id> --pick 1,4 --answer-file …`) → 「지금부터 제가 맡겠습니다: 크롬으로 웹 일. … 먼저 「데스크톱 앱 화면 조작」부터 하겠습니다 — 1단계(1/5): …」 그대로.
- 사용자: 했어.
- 마스터: (`recheck screen`) → 「아직 덜 됐습니다 — … 남은 단계: …」 또는 「확인했습니다. … 이제 제가 맡습니다.」 그대로.

## 확인
- `status` 에서 그 항목이 「맡는 중」이면 완료. 「지금 확인하니 꺼져 있습니다」가 붙으면 `recheck <ID>` 로 빠진 단계를 다시 안내한다.
