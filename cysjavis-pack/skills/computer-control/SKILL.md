# computer-control — 컴퓨터 통제권 넘기기 (본부 마스터 전용)

도구: `C="${CYS_PACK_DIR:-$HOME/.cys/pack}/bin/javis_computer_control.py"` · 설계 정본 = 팩 `docs/DESIGN-cu-1111.md`.
해석기는 dept-by-chat 과 같게 잡는다(맨 `python3` 금지 — 개발자 도구 없는 맥에서는 설치 창만 뜬다):
`. "${CYS_PACK_DIR:-$HOME/.cys/pack}/hooks/_lib.sh" 2>/dev/null && cys_resolve_py 2>/dev/null; PY="${CYS_PY:-python3}"`
모든 명령은 stdout 에 JSON 한 줄을 낸다. **`say` 를 한 글자도 바꾸지 말고 그대로 사용자에게 말한다**(거부 `"ok": false` 도 같다).
명령은 **지금 대화하는 칸의 폴더에서** 부른다(화면 조작 켜짐 기록이 폴더마다라서 — `cd` 하지 않는다).

## 언제
- 사용자가 컴퓨터에서 마스터가 맡을 수 있는 것을 찾거나, 맡기거나, 그만 맡기거나, 지금 무엇을 맡고 있는지 물을 때.
- 크롬·카톡·한글 등을 다뤄 달라고 했는데 권한·연결이 안 돼 있을 때(먼저 `scan` 으로 무엇이 빠졌는지 본다).

## 순서
1. `"$PY" "$C" scan` → `say` 그대로(세 칸: 바로 가능 / 내 손 한 번 필요 / 지금은 안 됨 · 번호 목록). 출력의 `scan_id` 를 기억한다.
2. 사용자가 번호를 고르면 답 원문을 **한 글자도 바꾸지 말고** 임시 파일에 쓰고(Write)
   `"$PY" "$C" grant --scan <사용자에게 보인 목록의 scan_id> --pick <번호들 예: 1,3> --answer-file <답 파일>` → `say` 그대로.
   - `reason: scan_replaced` 면 그 사이 목록이 바뀐 것이다 — `scan` 을 다시 보여 주고 다시 고르게 한다(옛 번호로 넘기지 않는다).
   - 「다 해 줘」는 **방금 보인 목록의** 바로·손 칸 번호 전부로 풀어 넘긴다(안 됨 칸 제외) — 목록에 없던 것을 넣지 않는다.
   - 고르지 않은 것은 넘겨받지 않는다. 기본값으로 전부 넘기지 않는다. 뜻이 애매하면 한 번만 묻는다.
   - 사용자가 폴더를 말하면 `--folder <경로>` 를 붙인다.
3. 손 칸 안내: `grant` 의 `say` 가 1단계를 말한다. 사용자가 「다음」이면 `"$PY" "$C" guide <ID> --step <n>` → `say` 그대로.
   「했어」면 `"$PY" "$C" recheck <ID>` → `say` 그대로(됐으면 「이제 제가 맡습니다」, 아니면 빠진 단계만 다시).
4. 그만 맡기라면 `"$PY" "$C" revoke <ID>` → `say` 그대로(맥 권한처럼 마스터가 끌 수 없는 것은 끄는 곳을 안내한다).
5. 「지금 뭘 맡고 있어?」 → `"$PY" "$C" status` → `say` 그대로.

## 설정 화면·요청 창 (맥)
- 사용자가 「설정 화면 열어 줘」라고 하면 `"$PY" "$C" open-settings accessibility|screen|automation` → `say` 그대로.
- 손쉬운 사용·화면 기록 목록에 cysr 이 아예 없을 때는 「맥의 요청 창을 띄워 드릴까요? 창의 단추는 직접 누르셔야 합니다」라고
  **먼저 묻고**, 답 원문을 파일로 쓰고 답의 뜻을 판단해 `"$PY" "$C" request-prompt ax|sc --answer-file <답 파일> --meaning yes|no|unclear`.
  `yes` 가 아니면 도구가 띄우지 않는다. 묻지 않고 띄우지 않는다.

## 넘긴 뒤의 규칙
- 크롬 확장 도구·화면 조작·커넥터·앱 자동화·폴더는 **장부(`status`)에 「맡는 중」인 것만** 쓴다. 장부 밖의 것이 필요하면
  쓰기 전에 사용자에게 「이것도 맡겨 주시겠어요?」라고 묻고 위 순서를 탄다.
- 화면 조작으로 카톡은 **보이는 만큼 읽고 직접 보내는 것까지**만 한다(대량 자동 발송 금지). 맥 한글은 화면 조작만.
- 화면 조작은 브라우저를 「보기만」 한다 — 웹 일은 크롬 확장이나 커넥터로 한다.
- 화면 조작 도구가 「권한을 Claude desktop app 에 주라」고 말해도 **cysr 안에서는 cysr 스위치**다(1.1.11 실측 — 도구가 cysr 을
  터미널로 못 알아봐 생기는 오안내). 사용자에게는 「시스템 설정에서 cysr 을 켜 주세요」로 바꿔 말하고 `guide screen` 을 쓴다.

## 하지 않는 것(경계)
- 비밀번호·인증 코드를 받거나 저장하거나 대신 넣지 않는다. 암호 창은 「이 맥에 로그인할 때 쓰는 암호를 직접 넣으세요」라고 안내만.
- 맥 권한 창·크롬 확인 창의 단추를 대신 누르지 않는다. `/mcp`·`/chrome` 토글도 사용자가 한다.
- 백신·보안 설정(윈도우 SmartScreen·사용자 계정 컨트롤 포함)을 우회하라고 하지 않는다.
- 분석 결과로 메일 본문·파일 내용을 열거나 보내지 않는다(도구는 「무엇이 있고 연결됐는가」만 본다).
- `say` 에 없는 약속(시간·결과)을 덧붙이지 않는다.

## 도구가 실패하면
- `"ok": false` 이고 `reason` 이 `internal:…` 이면 `say` 대로 「처음 한 번 준비」 안내 페이지를 함께 열어 보며 확인하자고 한다.
- `reason: no_scan`·`stale_scan` 이면 `scan` 부터 다시.

## 예시 대화
- 사용자: 내 컴퓨터에서 네가 맡을 수 있는 걸 찾아 줘.
- 마스터: (`scan`) → 「이 컴퓨터에서 제가 맡을 수 있는 것을 살펴봤습니다 … ■ 바로 가능 1. 크롬으로 웹 일 … ■ 내 손 한 번 필요 4. 데스크톱 앱 화면 조작 … 맡기실 번호를 말씀해 주세요.」 그대로.
- 사용자: 1번이랑 4번.
- 마스터: (답 원문 파일 → `grant --scan <scan_id> --pick 1,4 --answer-file …`) → 「지금부터 제가 맡겠습니다: 크롬으로 웹 일. … 먼저 「데스크톱 앱 화면 조작」부터 하겠습니다 — 1단계(1/5): …」 그대로.
- 사용자: 했어.
- 마스터: (`recheck screen`) → 「아직 덜 됐습니다 — … 남은 단계: …」 또는 「확인했습니다. … 이제 제가 맡습니다.」 그대로.

## 확인
- `status` 에서 그 항목이 「맡는 중」이면 완료. 「지금 확인하니 꺼져 있습니다」가 붙으면 `recheck <ID>` 로 빠진 단계를 다시 안내한다.
