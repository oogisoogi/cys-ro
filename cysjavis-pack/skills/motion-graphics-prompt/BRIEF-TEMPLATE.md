## 6. 제작 규칙(A 는 바꾸지 않는다 · B 는 4칸에서 일부러 요청한 것만 예외)

### A. 도구 계약 — 어기면 우리 도구가 찍지 못한다
1. **화면 = 시간의 함수.** 페이지는 1920×1080 HTML 한 장이다. 모든 위치·크기·색·투명도·글자는 `window.seek(t)`(t = 초)가 t 만 보고 정한다. 브라우저가 스스로 돌리는 움직임(CSS keyframes·transition·setInterval·requestAnimationFrame 반복)이나 앞 프레임에서 남겨 둔 값에 기대지 않는다. 무작위가 필요하면 시드 난수(예: mulberry32 · 시드 고정)만 쓴다 — `Math.random()`·`Date`·`performance.now()` 는 불러올 때 한 번이라도 쓰지 않는다(스틸 실행과 영상 실행의 그림이 달라진다). 앞 순간이 다음 순간을 정하는 물리는 불러올 때 끝까지 미리 계산해 두고 seek(t) 는 꺼내 읽기만 한다.
   - 왜: 같은 t 는 언제 찍어도 같은 그림이어야 스틸과 영상이 일치한다. `seek_render.js` 가 스틸마다 이것을 검사한다(결정론=OK/FAIL).
2. **GSAP 을 쓸 때**: 타임라인 하나를 `gsap.timeline({paused:true})` 로 만들고 `window.seek = t => tl.seek(t, false)` 로 연결한다. 자막·글자 교체도 그 타임라인 안에서 t 로 정한다. `tl.play()`·`gsap.to` 단독 실행·`lagSmoothing` 에 기대는 코드는 쓰지 않는다. (GSAP 표준 라이선스 = 상업 사용 무료)

### B. 연출 기준
3. **감속은 수식으로.** 들어와서 멈추는 움직임은 t 로 계산한 감쇠 곡선(지수 감속·감쇠 스프링 꼴)으로 쓴다. 빠르게 지나가는 요소는 이동량에 맞춰 흐리게 해 끊겨 보이지 않게 한다.
4. **장면은 이어받는다.** 다음 장면은 앞 장면에 있던 도형·글자·색이 모양과 자리를 바꿔 만들어진다. 화면을 통째로 끊거나 겹쳐 녹이는 전환은 쓰지 않는다.
5. **값싸 보이는 효과를 피한다.**
   - 번쩍임 계열: 입자 터짐 · 번지는 광채 · 렌즈 플레어
   - 흔들림 계열: 화면 떨림 · 색 채널 어긋남(RGB 분리)
   - 맥 빠짐 계열: 반 초 넘게 멈춰 있는 화면 · 튕기며 멈추는 감속
   - 기성품 계열: 무난한 그라데이션 배경 · 템플릿처럼 보이는 구성
6. **글자.** 한 화면의 글자 크기는 세 단계 이내 · 행간은 좁게 · 겹침과 잘림은 없게.

> 6칸 B 는 Prompt Motion(https://prompt-motion.com/) 공개 템플릿이 제시하는 제작 방향을 참고해 우리 말과 우리 분류로 다시 정리한 것이다.

## 7. 순서(관문)
**렌더는 아직 하지 않는다. 먼저 두 가지만 보여 달라.**
- 스토리라인: 전체 길이를 장면으로 나누고, 장면마다 「몇 초~몇 초 · 화면에 무엇이 보이고 어떻게 움직이나」를 한 줄씩.
- 대표 스틸 2장: HTML 을 먼저 만들고 `node tools/seek_render.js <page.html> --out <폴더> --stills <초1>,<초2>` 로 찍어 `결정론=OK` 줄과 함께 보여 준다.
- 내가 보고 고친 뒤에 `--duration` 으로 영상을 만든다. 영상을 본 뒤 고칠 때도 **다시 스틸 2장부터**.

## 8. 내레이션 기반(있을 때만)
- 첨부: 내레이션 음성(wav) · 자막(SRT) · 배경음(선택)
- 길이 = 내레이션 길이 + 1초
- 먼저 문장마다 「문장 번호 | 문장 | 화면에 보일 것 | 움직임(문장 안 몇 % 또는 낱말)」 표 → 확인 뒤 스틸 2장(7칸 관문 그대로)
- 대본만 있으면(음성·SRT 없음) 스킬 `narrated-motion` 을 쓴다 — 문장별 무료 음성·CUE 표·SRT 를 한 번에 만들고, 완성 영상의 소리·그림 시작을 문장마다 잰다(±0.2초).
- 움직임은 초가 아니라 **문장 번호**에 묶는다 — 페이지 안에 `const CUE = [{n:1, start:…, end:…}, …]`(문장별 합성 길이를 누적한 표 · `video-report-deck/bin/build.py` 와 같은 계산)를 두고 장면은 `CUE[k].start + 오프셋` 으로 쓴다. 대본을 고치면 CUE 만 다시 뽑는다. 특정 낱말에 맞추려면 `caption-align` 의 낱말 시각을 CUE 에 덧붙인다.
