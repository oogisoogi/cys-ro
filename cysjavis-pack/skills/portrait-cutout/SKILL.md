# portrait-cutout — 사진 배경 지우기(누끼) + 입체 보정

## 언제 쓰나
- 인물·사물 사진에서 배경을 걷어 **투명 바탕 그림**이 필요할 때 — 홈페이지 첫 화면(히어로)의 인물, 발표 자료에 얹을 사진, 포스터 합성.
- 원본이 고화질이 아니어서 **오린 뒤 또렷함·입체감까지 끌어올려야** 할 때(가장자리 정리 · 국부 대비 · 윤곽 안쪽 음영).
- AI 그림 생성기가 투명 바탕을 못 줄 때 → 처음부터 **초록(#00FF00) 바탕으로 그리게 하고** 이 스킬의 `--green` 으로 초록을 뺀다.
- 쓰지 않는 경우: 그림을 새로 생성·편집(→ media-gen · media-gen-edit), 영상에서 배경 빼기(이 스킬은 낱장 그림만).

## 순서
스크립트 위치: `"${CYS_PACK_DIR:-$HOME/.cys/pack}/skills/portrait-cutout/scripts/portrait_cutout.py"` (옆의 `vision_mask.swift` 를 스스로 찾아 부른다 — 둘을 떼어 옮기지 않는다).

**A. 사진(맥 전용 · Apple Vision)**
1. 원본을 보고 오릴 물체 둘레를 비율로 정한다(`--crop x0,y0,x1,y1` · 0~1). 어깨가 원본 끝에 닿아 있으면 원본 끝까지 잡는다(덜 잡으면 잘린 어깨가 평평하게 남는다).
2. 실행:
   ```bash
   python3 "${CYS_PACK_DIR:-$HOME/.cys/pack}/skills/portrait-cutout/scripts/portrait_cutout.py" 원본.jpg 결과.webp --crop 0.16,0.06,1,1
   ```
   - 출력은 `.webp`(q92 · 알파 · 웹용 기본) 또는 `.png`(32비트 RGBA). 높이 기본 994px(`--height`) · 머리 위 여백 40px(`--top-pad`).
3. 결과를 **어두운 바탕 위에서 확대 3곳**(어깨 · 귀 · 머리카락)으로 본다. 어깨·옷 둘레에 흰 테가 남으면 그 구역을 `--fringe-box x0,y0,x1,y1`(결과 그림 기준 비율 · 여러 번 가능)로 지정해 다시 돌린다 — 테를 같은 줄 안쪽 옷 결로 덮는다.
4. 쪽(웹)에 얹을 때 그림자·뒤 조명 값은 `references/cutout-notes.md` 「쪽에 얹을 때」.

**B. AI 생성 그림(초록 바탕 · 어느 기기든 · Pillow 만)**
1. 그릴 때 프롬프트 끝에 「그림자 없는 완전히 평평한 순초록(#00FF00) 단색 바탕 위에 따로 놓인 모습」을 영어로 붙이고, 옷·물건에는 초록을 쓰지 않게 한다(예문은 references).
2. 실행: `python3 ".../portrait_cutout.py" 그림.png 결과.png --green`
3. 어두운 바탕 위 확대로 가장자리에 초록 실선이 없는지 본다.

## 주의할 점
- **맥 전용**: 사진 모드는 macOS 14 이상 + swift(Command Line Tools)가 있어야 한다. 윈도우·리눅스에서는 「맥 전용 기능입니다」를 찍고 멈춘다(`--green` 은 어디서나 된다). macOS 14 근거 = Apple 개발자 문서의 `VNGenerateForegroundInstanceMaskRequest` 도입 판(https://developer.apple.com/documentation/vision/vngenerateforegroundinstancemaskrequest · 2026-11-06 문서 데이터 실측 「macOS 14.0」).
- 없으면 안내 후 멈춤(자동 설치 안 함): Pillow → `python3 -m pip install Pillow` · swift → `xcode-select --install` · macOS 13 이하 → 업데이트 안내.
- 종료 코드: 0 성공 · 1 처리 실패(예: Vision 이 앞 물체를 못 찾음) · 2 사용법·입력 오류(없는 파일·0바이트·그림 아님·출력 확장자) · 3 맥 아님 · 4 macOS 버전·swift 없음 · 5 Pillow 없음.
- **사람 가림(person)이 아니라 전경 가림(foreground)을 쓴다** — 사람 가림은 해상도가 낮아 테두리가 번진다. 그 대신 사람 옆 물건(의자·탁자)도 함께 남을 수 있으니 `--crop` 으로 먼저 좁힌다.
- 가림은 흐리게 하지 말고 **단단하게 + 3px 깎기** — 흐림을 넣으면 테두리가 뿌옇게 보인다. 대가로 머리카락 잔털이 깎여 머리선이 매끈해진다(알려진 한계).
- **256색 PNG 로 줄이지 않는다** — 피부에 계단 무늬가 생긴다. 용량은 WebP 로 줄인다.
- 초록 빼기를 「초록이면 투명」 단순 문턱으로 하면 가장자리 초록 실선이 남고, 흰 테두리 스티커를 둘러도 가려지지 않는다 → 반드시 `--green`(초록 우세도 알파 + 넘침 억제).
- 사진 처리는 화소 단위 반복이라 큰 원본(수천 px)은 수십 초 걸릴 수 있다 — `--crop` 으로 먼저 좁히면 빨라진다.
- 단계별 이유·바꾸면 품질이 떨어진 순서·알려진 한계: `references/cutout-notes.md`.

## 확인하는 방법
- 끝에 찍히는 JSON 한 줄: `opaque_pct`(완전 불투명 %) · `transparent_pct`(완전 투명 %) · `partial_pct`(반투명 가장자리 %). 투명이 0% 에 가깝거나 불투명이 0% 에 가까우면 가림이 실패한 것이다.
- 어두운 바탕(#140a1e 정도) 위에 얹어 확대해서 본다 — 흰 테·초록 실선·뭉개진 가장자리가 밝은 바탕에서는 안 보인다.
- 초록 모드: 보이는 화소(알파 ≥ 26) 중 `g − max(r,b) > 30` 인 화소 수 = 0 이어야 한다.
- **시험 입력 결과(2026-11-06 · macOS 26.6.2 · Pillow 12.3.0)**:
  ① 합성 사물 그림(연회색 바탕 · 주황 병 + 파랑 공 · 사람 없음) `.webp` → 839×1034 · 불투명 44.19% · 투명 52.27% · 반투명 3.54% · 4.6초 · 어두운 바탕 확인 OK(병·공 함께 남음 = foreground 의도대로).
  ② 순초록 바탕 합성 실루엣 `--green` → 640×480 · 불투명 29.29% · 투명 70.52% · 반투명 0.19% · 초록 실선 화소 **0**(스킬 없이 단순 문턱으로 대조 = **378**, 확대에서 머리 둘레 초록 실선 확인).
  ③ 지저분한 입력: 0바이트 `.jpg` → 「원본 파일이 비어 있습니다」 exit 2 · 글자 파일을 `.png` 로 바꾼 것 → 「그림 파일로 읽을 수 없습니다」 exit 2 · PATH 에서 swift 를 뺀 실행 → `xcode-select --install` 안내 exit 4. 실제 인물 사진·실제 AI 생성 그림·윈도우 실기는 시험하지 않았다(비맥·macOS 13 은 흉내 실행으로만 안내 문구 확인).
  ④ 임시 파일 청소: 사진 모드는 사진 사본·가림을 `portrait-cutout-*` 임시 폴더에 두었다가 가림을 읽자마자 지운다(swift 자체 임시 폴더도 그 안). TMPDIR 을 빈 폴더로 두고 성공 · 가짜 swift 실패(exit 1) · 깨진 가림(예외) · 뒤 단계 예외(`--fringe-box a,b`) · `--green` 5가지를 돌린 뒤 남은 항목 = 모두 0.
