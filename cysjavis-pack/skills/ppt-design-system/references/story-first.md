# 이야기 층 먼저 — 새 PPT 의 기본 절차(§0)

색·글꼴·크기·굵기(겉 층)보다 **내용의 흐름에 맞춰 맥락이 느껴지는 레이아웃**을 먼저 짠다. 원고를 장으로 잘라 꾸미는 것이 아니라, 이야기·논리가 흐르도록 장 하나하나의 배치를 설계한다.
근거: 같은 원고로 시범을 두 번 했을 때(2026-10-27·28), 겉 층만 바꾼 판은 「큰 차이 없음」, 이야기 층을 먼저 짠 판은 「맥락을 고려해 컷 자체의 레이아웃을 만든 것이 보인다」는 평가를 받았다.
⛔ 디자인(SKILL.md 순서 C)은 아래 5단계를 통과한 뒤에만 한다.

## 먼저 정할 것 5칸

`STORY.md` 맨 위에 적는다. 브리프·원고에 있으면 옮겨 적고, 없는 칸은 만드는 쪽이 정해 「정함」 표시를 붙인다 — 이 칸 때문에 되묻지 않는다.

| 칸 | 적을 것 |
|---|---|
| 누구에게 | 듣거나 읽을 사람 |
| 보고 나서 | 그 사람이 알게·정하게·하게 될 일 1문장 |
| 어떤 자리 | 발표(화면+말) / 읽는 자료 / 둘 다 — 주된 쪽 1개 |
| 발표 뒤 | 버림 / 배포 / 기록 보관 / 다음 일의 근거 |
| 원고 변형 | 그대로 / 구조만 재배치 / 자유 재구성 (셋 다 원고 밖의 새 주장·숫자 0) |

어떤 자리 → 한 장에 담는 양:
- 발표 = 한 장 한 주장 · 큰 숫자나 그림 · 설명은 발표자 노트로
- 읽는 자료 = 완결 문장·표 · 장 수를 줄임 · 노트는 보충
- 둘 다 = 주장 1개 + 짧은 근거

## 덱 갈래 1개

논리의 뼈대다(겉모양과 무관). 아래 5단계가 갈래마다 조금씩 다르다.

| 갈래 | 언제 | 5단계에서 달라지는 것 |
|---|---|---|
| 설득 | 결정·공감·참여를 끌어낼 때(제안·보고·세미나) | 그대로 |
| 가르침 | 강의·교육·안내서 | 2 = SCQA 대신 「앞 개념 → 뒤 개념」 배움 순서 · 3 = 제목은 「이 장이 가르치는 것」(주제 이름 금지는 유지) · 4 = 앞 장을 알아야 다음 장이 이해되는지로 판정 · 예시 먼저/설명 먼저는 배우는 사람 기준 |
| 안내 | 광고·일정·현황·자료집 | 1 = 주장 대신 「무엇을 빠짐없이 담았나」 · 2·4 생략 · 3 = 주제 이름 제목 허용 · 같은 급은 같은 모양 · 억지 결론·억지 반전 금지 |

## 5단계

1. **덱 메시지 1문장** + 구간별 역할 1문장씩.
2. **줄거리(SCQA)**: 상황 → 문제(긴장) → 질문 → 답. 「지금의 모습 ↔ 될 수 있는 모습」 대비가 오가게 한다. 원고 순서와 달라도 되지만 원고 밖의 새 주장·숫자는 0.
3. **주장 문장 제목**: 장 제목 = 완결된 주장(주제 이름 금지). 숫자·문장은 원천에서만 가져온다.
4. **제목만 읽기 시험**: 제목만 이어 적고, 장 사이에 접속어(그런데 · 그러니 · 그렇다면 …)가 붙는지 장마다 1줄로 판정한다. 끊기면 2·3단계로 돌아간다.
5. **논리 모양 → 레이아웃**(장마다 표로):
   - 대비 = 좌우 맞세움 / 막대 대비 · 변화 = 꺾이는 선 · 전후 · 원인 = 사슬 화살표 · 비율 = 점·도형 개수 / 면적 · 단계 = 계단 · 갈림 = 갈림길 · 간극 = 벌어지는 두 선
   - 근거 = 화면에는 숫자 하나 + 짧은 주장, 설명은 노트로
   - **한 장 한 메시지** · 줄글 목록 상자 금지(불가피하면 사유를 적는다)
   - ⚠ 서로 다른 문항·출처의 숫자를 같은 눈금 위에 놓지 않는다. 놓아야 하면 눈금을 가르고 문항을 장 위에 적는다(같은 눈금이면 오독된다).

## 산출 = STORY.md

- 덱 메시지 · SCQA 표 · 제목 줄거리 · 제목만 읽기 판정 · 장별 논리 모양 표
- 정직 고지: 원고와 순서를 바꾼 곳 · 화면에서 빼고 노트로만 보낸 내용
- 발표자 노트 = 원고 문단 원문 전부(빠짐 0)

## 기계 점검(만든 뒤)

- **화면 숫자·인용 대조**: 화면에 나온 숫자·따옴표 인용을 모두 뽑아 원고(원천)에 같은 글자로 있는지 하나씩 대조한다. 원고에 없는 숫자 = 고친다.
- **노트 빠짐 0**: 원고 문단을 하나씩 노트 전체 글에서 찾아 없는 문단을 센다. 0 이 아니면 고친다.
- 두 점검은 짧은 스크립트(문자열 포함 여부)로 돌리고, 결과 줄을 STORY.md 끝에 붙인다.
