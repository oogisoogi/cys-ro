# ASSET-LEDGER — 우리 자산(스킬·도구·자료) 판정표

> 한 장 정본. 본부에 등록된 스킬·도구·자료가 사용자 판(팩)에 들어가는지를 **항목마다 한 줄**로 적는다.
> 이 표에 없는 새 항목이 원천에 생기면 발행 게이트가 붉어진다(`scripts/asset_ledger_check.py` · 아래 §3).
> 작성 = TICKET=cysr-1116-asset-skills-1120 (2026-11-20 · 기준판 1.1.16 dea2e1853).

## 1. 판정 기준

- 11-06 기준(박사님 · master#7a471ca4):
  - ⑴ 완전 공개 배포(오픈 라이선스 또는 「자유롭게 복사해 쓰세요」 문장) = 원문 동봉
  - ⑵ 그 밖, 확신도 상 ∧ 결정적 유익 = 실행 때 받아 씀(런타임 참조)
  - ⑶ 나머지 = 우리 말 요약
- 개인정보·교회 내부 자료가 든 것은 넣지 않는다. 사용자 이름이 든 절대 경로는 0 이어야 한다.
- 11-20 덧붙임(박사님 08:3x · master#5a3e7ccc): 업데이트 반영도 고려하고, **초보 사용자에게 도움이 되는지**를 함께 본다.
  - 「초보 유익」 칸 = 상/중/하. 보는 것: 왕초보가 말로 시켜도 쓰이는가 · 설정·용어 장벽 · 개인정보·비용 위험.
  - `—` = 사용자에게 갈 일이 없는 항목(개인정보·운영 기록 등)이라 매기지 않음.

## 2. 판정 어휘 (게이트가 읽는 값 — 이 여섯 중 하나)

| 판정 | 뜻 |
|---|---|
| `넣음` | 사용자 좌석 팩에 스킬·도구로 넣는다 |
| `넣음-자료` | 팩의 어느 스킬 `references/` 에 문서·참고 자료로 동봉한다 |
| `팩에있음` | 이미 팩에 있다. 판 대조(본부 판이 더 새것이면 갱신)를 근거 칸에 적는다 |
| `링크` | 바깥 원본을 동봉하지 않고 원본 주소·설치 명령만 둔다 |
| `전용` | master(본부) 전용. 이유(개인정보·교회 내부·바깥 재배포 불가·운영 전용·확신도 미달)를 근거 칸에 적는다 |
| `제외` | 우리 자산이 아님(동기 폴더 등) 또는 디스크에 파일이 없다 |

## 3. 원천과 항목 키 (게이트 계약)

게이트는 아래 원천을 훑어 항목 키를 만들고, 그 키가 §4 표 첫 칸에 있는지 본다.
표의 키 끝이 `*` 이면 그 앞부분으로 시작하는 키를 모두 덮는다.

| 원천 | 만드는 키 |
|---|---|
| 본부 스킬 폴더(여러 곳의 합집합 · 점으로 시작하는 이름 제외) | `skill:<이름>` |
| 본부 자산 폴더의 맨 위 항목 | `asset:<이름>` |
| 도구 묶음 폴더(`motion-graphics-prompt` · `ppt-design-system` · `portrait-cutout` · `video-production`) 안의 맨 위 항목 — 묶음 자체는 키를 만들지 않는다 | `asset:<묶음>/<이름>` |
| 본부 전용 원천(영상 검토 산출물) — 본부 판정표가 있을 때만 훑는다 | `path:<경로>` |

- 백업 사본(이름에 `.bak-`)과 점으로 시작하는 이름은 원천에서 뺀다.
- 원천 폴더가 없는 기계(CI·사용자 기계)에서는 원천 대조를 건너뛴다(「원천 없음」 — 붉음 아님 · 판정 값·팩 실재 검사는 그대로).
- 원천의 정확한 경로와 본부 운영에만 쓰는 줄은 본부 판정표 `docs/ASSET-LEDGER.hq.md` 에 있다(공개 트리에는 없다). 검사기는 이 판정표 옆에 `.hq.md` 가 있으면 두 표를 합쳐 읽는다. 같은 키가 두 표에 있으면 붉다.
- 「있는 곳」 칸의 「본부」 = 본부 스킬 폴더 전부(어느 폴더인지는 본부 판정표).
