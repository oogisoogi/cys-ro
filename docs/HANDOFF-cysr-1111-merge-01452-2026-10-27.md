## 3. 2단계 — master 발신 배선 수리

### 3-1. 문제(재확인)

0.14.52 데몬은 **에이전트 좌석에 온 Return 없는 직접 본문을 화면에 치지 않고 잡아 둔다**(`held:"awaiting_submit"` · `src/bin/cysd/submit_assoc.rs:21` 60,000 ms · 분류 `src/bin/cysd/handlers.rs` `direct_agent_intent`). 같은 호출자(①검증된 좌석 ②자기신고 from ③**cys 프로세스의 부모 pid+출생 시각**)의 `send-key Return` 이 와야 본문과 Return 을 한 작업으로 쓴다. CLI 는 그래도 `OK` · rc 0 을 찍는다.
- master-send.sh `bk_send` 는 `$(…)` 안에서 보낸다 → bash 3.2 명령 치환 = 부모가 서브셸 → Return 과 짝이 어긋남.
- 그 전에 master-send.sh·spawn-worker.sh 는 「입력칸에 본문이 실린 것을 본 뒤에만 Return」(고스트 방벽)인데, 본문이 화면에 안 실리므로 Return 자체를 안 보낸다 → **60초 뒤 본문 폐기 · rc 0 · 조용한 유실.**
- master-cycle-exec.sh 는 cys 를 직접 부르지 않는다(cmux 자기 /remote-control 과 `master-send.sh --cycle` 위임뿐) → master-send.sh 수리로 함께 해소.
