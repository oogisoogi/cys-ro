# cysr 1.0.0

> 초안 — 발행 전 검토용(TICKET=cysr-brand-version · 2026-09-15). 발행 본문에 옮길 때 이 인용 줄은 뺍니다.

## 이름이 cysr 로, 판 번호가 1.0.0 으로 바뀌었습니다

지금까지 쓰시던 터미널의 새 이름은 **cysr** 입니다. 판 번호도 새로 시작해 이번이 **1.0.0** 입니다.
그동안 윈도우판은 0.14.36, 맥판은 0.14.37 로 번호가 서로 달랐는데, 이번부터 두 운영체제 모두 같은
번호를 씁니다.

- 창 제목, 화면 왼쪽 위 이름, Control Center 아래쪽 안내가 **cysr** 로 보입니다.
- 이미 설치하신 분은 **다시 설치하실 필요가 없습니다.** 앱 위쪽의 **Update** 버튼으로 받으시면
  지금 쓰시던 자리에 그대로 새 판이 들어갑니다. 설정·작업 폴더·대화 기록도 그대로입니다.
- 설치 위치와 프로그램 파일 이름은 바꾸지 않았습니다. 그래서 다음 곳에서는 여전히 **cys** 라는
  이름이 보입니다. 같은 프로그램이니 걱정하지 않으셔도 됩니다.
  - 맥: 응용 프로그램 폴더, Dock, 시스템 설정의 권한 목록
  - 윈도우: 설치 프로그램 창, 설치된 앱 목록
  - 공통: 터미널에서 입력하는 명령어 `cys`

## 윈도우에서 검은 창이 잠깐씩 뜨던 문제를 고쳤습니다

윈도우에서 일정한 간격으로(대략 1분마다) 검은 창이 번쩍였다가 사라지는 일이 있었습니다. 뒤에서
주기적으로 도는 점검 작업이 창을 숨기지 않고 실행된 탓이었습니다. 이번 판부터는 그 작업들이 창
없이 조용히 돕니다.

## 같은 판 번호라도 내용이 바뀌면 업데이트를 받습니다

앞으로는 판 번호가 같더라도 내용이 바뀐 수정본이 나오면 Update 버튼으로 받을 수 있습니다. 반대로
이미 받은 것과 똑같은 판이면 다시 받지 않습니다. 원칙적으로는 수정할 때마다 판 번호를 올려서 내보냅니다.

## 피드백 보내기

화면 왼쪽 목록 아래에 **피드백 보내기** 단추가 생겼습니다. 불편한 점이나 문제를 사진·영상과 함께
운영팀에 바로 보내실 수 있습니다.

## 자동 업데이트 서명 키를 새 키로 옮기는 준비를 했습니다

이번 판은 지금까지 쓰던 서명으로 배포되고, 안에는 새 서명 키가 함께 들어 있습니다. 그래서 다음 판부터
새 키로 서명해도 Update 버튼이 그대로 작동합니다. 따로 하실 일은 없습니다.
