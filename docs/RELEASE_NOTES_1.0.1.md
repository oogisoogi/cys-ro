# cysr 1.0.1

> 초안 — 발행 전 검토용(TICKET=cys-v101-integrate ⓕ · 2026-09-16). 발행 본문에 옮길 때 이 인용 줄은 뺍니다.

## ⚠ 0.14 판을 쓰시는 분은 다시 설치해 주세요

이번 판부터 자동 업데이트와 팩 갱신의 서명 키가 새 키로 바뀌었습니다. 1.0.0 을 설치하신 분은 앞으로도
**Update** 버튼으로 그대로 받으시면 됩니다. 그런데 1.0.0 을 거치지 않고 아직 **0.14 판**(0.14.29~0.14.37)을
쓰시는 분은 앱 안의 Update 버튼으로 1.0.1 을 받을 수 없습니다(새 서명을 옛 앱이 알아보지 못합니다).
이 경우 홈페이지에서 **설치 파일을 새로 받아 다시 설치**해 주세요. 설정·작업 폴더·대화 기록은 그대로 남습니다.

## 이름이 설치 화면과 앱 목록까지 cysr 로 바뀌었습니다

1.0.0 에서는 창 제목만 cysr 였고 설치 프로그램과 앱 목록에는 cys 가 남아 있었습니다. 이번 판부터는
보이는 이름이 모두 **cysr** 입니다.

- 윈도우: 설치 프로그램 창, 설치된 앱 목록, 시작 메뉴·바탕 화면 바로가기가 cysr 로 보입니다. 설치 폴더는
  예전 자리를 그대로 씁니다. 예전 이름(cys)으로 남아 있던 앱 목록 항목과 바로가기는 이번 설치에서 정리됩니다.
- 맥: 새로 설치하시면 응용 프로그램 폴더에 **cysr.app** 으로 들어갑니다. 이미 cys.app 으로 설치하신 분은
  그 이름 그대로도 정상 설치로 인정됩니다.
- 내려받는 파일 이름도 cysr 로 시작합니다(예: `cysr_1.0.1_x64-setup.exe`).

## 터미널 명령어를 cysr 로도 쓸 수 있습니다

터미널에서 `cysr` 라고 입력해도 `cys` 와 똑같이 동작합니다. 맥은 명령어 설치 단추로, 윈도우는 설치
프로그램이 자동으로 준비합니다. 예전처럼 `cys` 로 입력하셔도 됩니다.

## 윈도우에서 검은 창이 잠깐씩 뜨던 문제를 마저 고쳤습니다

1.0.0 에서 고친 뒤에도 일부 윈도우 컴퓨터에서는 약 2초마다 검은 창이 번쩍였습니다. 사무실 화면을
아무도 보고 있지 않을 때도 뒤에서 상태를 묻는 작업이 계속 돌았고, 그 작업과 몇몇 점검 작업이 창을
숨기지 않은 채 실행된 탓이었습니다. 이번 판부터는 보는 사람이 없으면 그 작업을 쉬고, 뒤에서 도는
작업은 모두 창 없이 실행됩니다.

## 자비스 팀원이 지시만 받아 두고 멈춰 있던 문제를 고쳤습니다

"너는 마스터다"로 팀을 띄웠을 때 CSO 나 워커 자리의 입력줄에 [Pasted text #1 +529 lines] 같은
표시만 남고, Enter 가 들어가지 않아 그 자리가 계속 기다리기만 하는 일이 있었습니다. 이번 판부터는
팀원 자리를 띄운 뒤 그 자리가 지시를 실제로 받았는지 대화 기록으로 확인하고, 받지 못했으면 Enter 를
대신 눌러 줍니다(최대 세 번). 그래도 받지 못한 자리는 마스터에게 알려서 마스터가 다시 확인합니다.
직접 Enter 를 누르실 필요가 없습니다.

## Update 표시와 버튼이 서로 다르게 동작하던 문제를 고쳤습니다

위쪽 Update 표시에 숫자가 떠 있는데 눌러 보면 "최신입니다"만 나오는 일이 있었습니다. 표시를 만든
확인 결과와 버튼을 눌렀을 때 쓰는 결과가 서로 다른 시점의 값이었기 때문입니다. 이번 판부터는 버튼을
누를 때마다 새로 확인하고, 그 결과로 표시 숫자도 함께 고칩니다.

## 판 번호가 늘 보입니다

화면 왼쪽 위 cysr 이름 옆에 지금 쓰고 계신 판 번호가 항상 표시됩니다. 번호 위에 마우스를 올리면 더 자세한
빌드 정보가 보입니다. 뒤에서 도는 프로그램이 다시 켜진 뒤에도 화면에 옛 프로그램 번호가 남아 있던
문제도 함께 고쳤습니다.

## 윈도우에서 켤 때마다 승인 알림이 쌓이던 문제를 고쳤습니다

일부 윈도우 컴퓨터에서 cysr 를 켤 때마다 "자원 점검" 승인 알림이 올라와 Control Center 에 표시가 계속
남아 있었습니다. 윈도우에 없는 점검 도구를 찾지 못한 것을 "점검 실패"로 잘못 센 탓이었습니다. 이번
판부터는 그 경우를 실패로 세지 않아 알림이 뜨지 않습니다. 실제로 컴퓨터가 과부하일 때의 알림은 그대로입니다.

## 서명 키를 새 키로 옮기는 일을 마쳤습니다

1.0.0 에서 예고한 대로 이번 판부터 자동 업데이트와 팩 갱신이 새 키로 서명됩니다. 1.0.0 을 설치하신 분은
따로 하실 일이 없습니다. 0.14 판을 쓰시는 분은 맨 위 안내대로 다시 설치해 주세요.
