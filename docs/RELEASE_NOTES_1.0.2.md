# cysr 1.0.2

## 컴퓨터 부하가 잠깐 높을 때 팀 자리 띄우기를 바로 멈추지 않습니다

팀 자리를 띄우기 전에 cysr 는 컴퓨터 부하를 한 번 확인합니다. 설치 직후나 막 켠 직후처럼 부하 수치가
잠깐 높게 잡히면, 예전에는 그 한 번의 확인만으로 팀 자리 띄우기를 멈췄습니다. 이번 판부터는 부하 수치
때문에 멈춰야 하는 경우에 한해 30초 간격으로 최대 6번(최대 3분) 다시 확인하고, 그 사이 부하가 내려가면
그대로 이어서 띄웁니다. 3분 뒤에도 높으면 예전처럼 멈추고 알립니다. 부하가 아닌 다른 이유로 멈춰야 할
때는 기다리지 않고 예전처럼 바로 멈춥니다.

## 다시 시작한 뒤 빈 자리를 살아 있는 자리로 잘못 보던 문제를 고쳤습니다(맥)

컴퓨터나 cysr 를 다시 시작한 뒤 팀 자리를 되살릴 때, 자리 이름표는 남아 있지만 그 안의 AI 프로그램은
실행되고 있지 않은 자리를 "살아 있음"으로 판정하는 일이 있었습니다. 이번 판부터는 그 자리 안에서 AI
프로그램이 실제로 실행 중인지도 확인하고, 실행 중이 아니면 그 자리를 새로 띄웁니다. 이 확인은 맥에서
동작하며, 윈도우에서는 예전 판정 방식을 그대로 씁니다.

## 작업자 자리가 지시를 받기 전에 스스로 일을 시작하지 않도록 안내를 더했습니다

- 작업자 자리가 처음 켜질 때, 지시를 받기 전에는 어떤 작업도 스스로 정하거나 시작하지 말고 질문만
  하도록 안내하는 문구가 함께 들어갑니다.
- 되살린 자리에서는 cysr 가 그 자리의 대화 기록을 직접 세어, 아직 받은 지시가 한 건도 없으면 "지시를
  받기 전까지 작업하지 말고 질문만 하라"는 안내를 넣습니다. 프로그램이 자동으로 넣은 문구는 이 셈에서
  뺍니다.

## 팀 자리가 화면에 붙을 때 마스터 자리 칸이 좁아지던 문제를 고쳤습니다

팀 자리가 하나씩 화면에 붙을 때마다 기존 화면 전체를 반으로 나눠, 칸이 넷이면 마스터 자리 칸이 화면의
8분의 1까지 좁아졌습니다. 이번 판부터는 칸이 가로로만 나뉘어 있을 때 자리 순서는 그대로 두고 마스터
자리 칸을 화면의 3분의 1로(칸이 둘이면 절반으로), 나머지 칸은 같은 폭으로 다시 맞춥니다. 칸을 세로로도
나누어 직접 배치해 두신 화면은 건드리지 않습니다. 가로로만 나뉜 화면에서 칸 경계를 끌어 맞춰 두신
폭은 새 자리가 붙을 때 다시 맞춰집니다.

## 폴더 접근 안내에 앱 이름을 cysr 로 표기합니다(맥)

문서·데스크탑 폴더 접근이 막혔을 때 뜨는 안내에서, 시스템 설정에서 허용할 앱 이름을 cys 가 아니라
실제 목록에 보이는 이름인 **cysr** 로 안내합니다.

## 개발자 도구가 없는 맥에서 자동 점검 기능이 조용히 멈추던 문제를 고쳤습니다(맥)

개발자 도구(Command Line Tools)가 설치되지 않은 맥에서, cysr 의 자동 점검 기능들이 쓸 수 없는 시스템 기본
파이썬을 골라 조용히 실패하고 개발자 도구 설치 창을 띄울 수 있었습니다. 이번 판부터는 cysr 앱에 들어 있는
파이썬을 먼저 쓰고, 개발자 도구가 없는 맥에서는 시스템 기본 파이썬을 고르지 않습니다.

## 내부 시험을 보강했습니다

이번 판에서 고친 자리 시작 안내와 되살린 자리 판정을 확인하는 시험이 자동 시험 과정에서 함께 실행되도록
추가했습니다.
