## 모양 어휘 — 정본 = 기존 역할 점(1f · master#94f497c9 ②)

같은 값은 같은 모양이다. 창 머리의 역할 점(style.css `.pane .pane-role-dot act-*`)을 정본으로 삼고, 좌석 줄·상황판이 같은 클래스를 쓴다.
판정도 하나다(seatrows.seatDot — 역할 점과 좌석 줄이 함께 부른다).

| 값 | 역할 점(창 머리 · 그대로) | 좌석 줄(1b → 1f) | 상황판(1d → 1f) |
|---|---|---|---|
| 작업 중 | 역할색 채운 원 · 깜박임(움직임 줄임 = 이중 고리) | 초록 ● → 역할 점과 같음 | 초록 ● → 같은 모양(글자색) |
| 대기 | 역할색 채운 원 · 고정 | 노랑 ◆ → 역할 점과 같음 | 노랑 ◆ → 같은 모양 |
| 막힘(승인 창 · 입력 대기) | 역할색 마름모(입력 대기) — 1f 부터 승인 피드 대기도 여기 | 빨강 ▲ → 마름모 | 빨강 ▲ → 마름모 |
| 모름 | 역할색 빈 원 | ○ → 역할 점과 같음 | ○ → 같은 모양 |
| 끝남 | 점 숨김 | 「–」 → 빈 칸(흐린 줄) | 세지 않음 |

한 화면에 뜻이 다른 ◆ 는 없다(종전 좌석 줄 ◆ = 대기 · 역할 점 마름모 = 입력 대기 가 겹치던 것 해소). 「승인 창」·「확인」 꼬리표는 글자 그대로 남는다.
