## 1. 결함 한 줄
화면 출력 건강 규칙 `rate_limited` = `(?i)rate.?limit(ed)?|too many requests|\b429\b`(`src/bin/cysd/state.rs:8787-8790`)가 **모든 좌석의 모든 출력 줄**을 본다(`ingest_output` :7840-7913 → `run_health_rules` :7941-8070). CSO 의 경보 보고를 **다른 좌석이 인용·재진술**하면 그 좌석 이름의 `health.alert` 가 생겨 CSO 로 되돌아간다(`alert_route.rs` 자기제외 :1167-1169 는 「대상 = CSO 좌석」일 때만). 기본 규칙에 자동 조치는 없다(`action: None` :8798). 부작용 = 소음 + 일반 경보 시간당 20건 몫(`HOURLY_CAP` :69)을 거짓 경보가 채우면 진짜 `surface.exited`·`watchdog.*` 가 최대 약 1시간 **보류**(폐기 아님).

이미 있는 방어(통과 구멍 포함): 주입 직후 2초 메아리 창(:7943-7948) · 「경보 논의」 억제 `alert_discourse_reason`(:8663-8694 — 우리 식별자 · 밑줄 규칙명 · 따옴표 · **한 물리 줄 안** 한글 8자+) · 30초 디바운스 · 키별 5분 쿨다운. 구멍 = 영어 재진술 · 접힌 줄(한글 8자 미만 조각) · 맨 숫자 `429`(「PR #429」).

## 2. 안 A — 출처 창: 「경보 문구를 받은 좌석」을 일정 시간 의심한다
- **무엇**: 데몬이 좌석 T 에 **경보 유래 본문**(CSO 발신 · `[alert]` 렌더 · 경보 키를 인용한 전송)을 주입한 순간 T 에 `alert_quote_until = now + N분`(기본 10분 · 규칙별) 표지를 단다. 그 창 안에서 T 의 같은 규칙 탐지는 **발행하지 않고** `recent_health` 에 `reason = "discourse:quoted"` 로만 남긴다(인증 재시작 잠금 `AUTH_INTERLOCK_RULES` :8710 은 기록을 계속 보므로 그 기능은 그대로).
- **출처 판정 재료**: 이미 있는 것만 쓴다 — 주입 원장(발신자 = CSO 좌석 · 본문에 경보 키 해시/마스크 토큰 `‹health-rule›` 포함 여부), 경보 라우터의 배달 기록(키 · 대상 좌석).
- **장점**: 좌석이 무엇이라고 다시 말하든(영어 · 줄 접힘) 출처로 막는다 · 정규식 무변경이라 진짜 탐지율 손실 0(창 밖).
- **단점·위험**: 창 안의 **진짜** 429 를 늦게 본다(최대 N분) · 좌석별 상태 + 정리 경로 추가(`governance.rs` 좌석 정리 :5534 와 같은 꼴 필요) · 잠금 순서 주의(주입 경로 ↔ 건강 규칙 경로). 크기 ≈ 40~80줄 + 시험(위험 중).

## 3. 안 B — 내용 서식: 규칙을 「공급사 오류 서식」으로 좁힌다
- **무엇**: `rate_limited` 를 사람·에이전트가 거의 재진술하지 않는 **기계 서식**만 잡게 바꾼다 — 예: `rate_limit_error`(API 오류 형식) · `HTTP 429` · `429 Too Many Requests` · `usage limit reached`(공급사 문구) · 줄 머리 기준(`^\s*(Error|API Error)[: ]`). 맨 `rate limit` · 맨 `429` 는 뺀다. 보조로 `health.alert` 에 **별도 시간당 몫**을 준다(일반 몫 20 과 분리 · `CLEAR_RESERVE` 와 같은 꼴) — 거짓 경보가 남아도 진짜 자가치유 경보를 막지 않게.
- **장점**: 작다(규칙 ≈5줄 + 시험 ≈15줄 · 몫 분리 ≈20~40줄) · 상태 추가 0 · Claude·agy 좌석은 이미 상태줄 `usage.report` → `alert.rate_limit`(`alerts.rs:175-185`)로 한도를 보고하므로 화면 규칙은 대부분 중복 보험이다.
- **단점·위험**: 비-Claude 에이전트의 다른 문구는 놓칠 수 있다(탐지율 감소) · 서식 목록 유지 비용 · 출처 문제 자체는 남는다(기계 서식을 그대로 붙여 넣은 인용은 여전히 잡힌다).
