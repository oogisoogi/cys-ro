## 윈도우 영향 지점
1. 같은 `ui/` 파일이 윈 빌드에 그대로 들어간다 — 이 단추들에는 플랫폼 분기가 없다(`IS_WINDOWS` 사용처 0). 맥/윈 같은 판.
2. **글꼴 폭**: 윈은 Segoe UI + 맑은 고딕으로 그려 한글 단추 폭이 맥과 다르다. 800폭 넘침 0 은 맥 글꼴 헤드리스 실측이고 윈 실측은 없다.
3. **가로 스크롤 막대**: 상단바가 넘치면(`overflow-x: auto`) 윈 WebView2 는 막대가 보일 수 있고 높이 38px 상단바 안에서 단추 일부를 가릴 수 있다. 1.1.9 도 640폭에서 같았지만 단추 2개가 늘어 넘치기 시작하는 폭이 넓어졌다(맥 글꼴 기준 셈: 1.1.9 = 640 + 26 ≈ 666폭 · 지금 뱃지 켬 = 640 + 132 ≈ 772폭).
