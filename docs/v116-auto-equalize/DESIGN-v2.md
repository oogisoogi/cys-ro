# 자동 정렬 v2 — 워커 「기둥」 폭만 균등 (TICKET=v116-equalize-v2 · cysr 1.1.6 사양 교정)

「마스터:cso는 세로로 4:1 비율일 것이다. 이것은 그대로 유지한다. 사용자가 임의로 세로로 정렬한 것들도 그대로 유지한다.
오직 워커 페인들의 좌우폭만 균등하게 정렬한다.」 + 「(팔레트 세로 분할 제거 건은) 1번으로 해결되었을 것이다.」

## v1 과 달라지는 한 점
v1 은 워커 쪽 좌석을 **한 줄로 폈다**(사람이 위아래로 나눈 칸도). v2 는 워커 쪽을 **기둥** 단위로 본다.

- **기둥(unit)** = 트리 루트에서 가로(row) 분할만 따라 내려가 만나는 첫 「가로 분할이 아닌」 서브트리 —
  칸 하나 또는 위아래(col) 분할 묶음(그 안의 모양은 무엇이든). 루트를 가로 분할로 끝까지 펼친 목록 = 기둥 목록.
- 좌열(master·cso)은 기둥 하나여야 한다(v1 의 「루트까지 전부 row 길 + 정확히 좌열 좌석만」 조건과 같은 말).

## 새 규칙
1. 좌열 = v1 그대로(서브트리 보존 · 위아래 비율 · D1=C 가로 몫 · F1 깊은 길 · F4 master-2 승격).
2. 워커 기둥 = 입력 트리의 기둥 중 좌열 좌석을 품지 않은 것 · **객체 그대로 보존**(안의 위아래 비율 무접촉).
   결과 = row(몫, 좌열, evenRow(워커 기둥들)) — 기둥끼리만 좌우 균등.
3. 열기 add {sid, after, dir?}:
   - dir 없음/"row"(자동 입양 · 새 창 · 오른쪽 분할) = 새 기둥. after 가 워커 기둥 안이면 **그 기둥 바로 오른쪽** ·
     after 가 좌열이면 워커 기둥 맨 왼쪽(v1 순서와 같음) · 없으면 맨 오른쪽.
   - dir "col"(팔레트 「세로 분할」) = after 칸을 col(after, 새 칸, 0.5) 로 바꿔 **그 기둥 안 아래**에 둔다(기둥 수 불변 = 폭 불변).
     after 가 좌열이면 좌열 무접촉 → 새 기둥(워커 맨 왼쪽) · after 없음 → 맨 오른쪽 새 기둥.
4. 닫기 remove: 기둥 안 칸 하나 = 그 자리에서 잘라내고 형제가 자리를 받는다(replaceNode 와 같은 접힘 · 기둥 폭 불변) ·
   기둥 전체가 사라지면 기둥 목록에서 빠지고 남은 기둥이 다시 균등.
   잘라낸 뒤 기둥이 가로(row) 분할로 남으면(옛 저장 배치의 col(row(a,b),c) 에서 c 닫힘) 그 가로 조각들을 기둥으로 펼친다
   (결과를 다시 넣어도 같은 결과 = 멱등 유지).
5. ~~좌열 가로 몫의 「워커 수」 = 워커 기둥 수~~ — **폐기(아래 「박사님 결정 14:5x」)**. (원문 보존:) 좌열 가로 몫의 「워커 수」 = **워커 기둥 수**(v1 = 워커 좌석 수). 모든 워커가 칸 하나 기둥이면 두 값이 같아
   현행 동작과 같다. 세로 분할·기둥 안 닫기가 좌열 폭을 바꾸지 않게 하려면 기둥 수여야 한다(사양 4 「기둥 폭은 그대로」).
6. 정렬 단추(mode "standard") = 현행 그대로(formationLayout 표준 · 사람이 누르는 것).
7. ~~보류 대비~~ — **해소(박사님 결정 14:5x)**. (원문 보존:) 보류 대비: LeftShareMode 판정은 `untouched` 한 줄에 모여 있다 — 「좌열 폭 언제나 보존」 답이 오면 그 줄을 끄는
   한 줄 변경(지금 동작 변경 0).

## 모호한 모양 처리표(auto 모드)
| 입력 모양 | v1 | v2 |
|---|---|---|
| 본부 좌석 없음(워커만) | 전부 한 줄 | 기둥 균등(위아래 묶음 보존) |
| 좌열이 기둥 하나(정상) | 좌열 보존 + 한 줄 | 좌열 보존 + 기둥 균등 |
| 트리 없음 · 좌열 좌석이 전부 「칸 하나 기둥」(첫 배치·row 뿐인 트리·master|cso 좌우 나란함) | 표준 전체 | 좌열만 표준으로 새로(4:1) + 워커 기둥 보존·균등(지워지는 사람 위아래 나눔 0) |
| 좌열 좌석이 워커와 한 기둥에 섞임(워커를 master 아래에 넣음 · 좌열이 위아래 분할 속 · 루트가 위아래 분할) | 표준 전체(사람 나눔 지움) | **무정렬** — 최소 변경만: remove = 그 자리 접힘 · add(after 있음) = after 칸을 dir 방향 반 나눔 · add(after 없음) = 루트 오른쪽에 새 칸(몫 1/(기둥+1)) |
| 역할이 바뀌어 좌열 좌석이 워커 기둥 안에 생김 | 표준 전체 | 위 행과 같음(무정렬) |
