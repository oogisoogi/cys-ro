## 단일 순수 함수 — `autoArrange(tree, roles, {add, remove}, mode)` (ui/src/formation.ts)
1. 순서 = 입력 트리 순회 순서 − remove(중복 제거) · add 는 `after` 바로 다음(없으면 끝).
2. 좌열 좌석 = 순서상 첫 master 계열 + 첫 cso 계열(formationLayout 과 같은 고르기). 없으면 전부 한 줄 균등(`evenRow`).
3. 입력 트리에서 좌열 찾기: 입력 기준 좌열 좌석을 **정확히 그것만** 덮는 가장 작은 서브트리 ·
   모양 = 칸 하나 또는 위아래(col) · 루트까지의 길이 전부 좌우(row) 분할. 성립하면 몫 = 길의 비율 곱.
   불성립(처음 배치 · 좌석 흩어짐 · 좌열이 워커를 품음 · 위아래 분할 속 · master|cso 좌우 나란함) → 표준(좌열 몫 leftColumnShare · 4:1).
4. 좌열 구성이 그대로면 그 서브트리를 같은 객체로 보존(위아래 비율 포함) · 좌열 좌석이 빠지거나 들어오면 좌열만 표준으로 짓고 몫은 이어받음.
5. 몫: D1=C(위) · 몫이 퇴화(1 = 좌열뿐이던 화면)면 표준.
6. 결과 = row(몫, 좌열, evenRow(나머지)) · 나머지 없으면 좌열만(래퍼 없음 = 07-27 붕괴 기전 ⑵ 회피).
- 정렬 단추 = 같은 함수 · mode "standard"(좌열까지 표준 = 종전 단추 결과와 같다 — 기존 기능 보존).
- **좌석 집합 보존**: 결과 sid 집합 = (입력 − remove) ∪ add. 이 함수는 좌석을 만들거나 지우지 않는다(4군 ④) — 속성 시험 3000 트리 × 2모드.
- 트리를 **먼저 감싸거나 잘라낸 뒤 부르지 않는다** — 좌열 몫을 그 순간 잃는다(그래서 add/remove 를 인자로 받는다).
- 죽은 좌석·자리표·역할 모르는 셸 = 역할 없으면 워커 줄. 빼는 것은 호출자의 remove(함수는 생존을 모른다).
- 역할 표 = 소켓별 마지막 list_surfaces(끝난 좌석의 역할도 남김 — 끝난 master 칸이 좌열에서 튀지 않게).
