## 설계
### 상태(단일 진실)
- `restartPendingVersion: string | null` — main.ts 모듈 변수 **하나**가 화면의 진실. `null` = 대기 없음.
- 설정 지점 = **`update-restart-required` 리스너 하나뿐**(맥 install_update_darwin 만 이 이벤트를 낸다 — 윈은 install_update_plugin 이 곧장 재시작 → 상태가 생길 곳이 없다).
- 해제 지점 = 없음(프로세스가 재시작으로 끝나면서 사라진다). 대기 중에 더 새 판 교체가 또 끝나면 같은 리스너가 판번을 덮는다.

### 새로고침(⌘R)에 남기기 — sessionStorage + 옛 앱 판번 짝
- 저장 = `sessionStorage["cys-restart-pending-v1"] = {"version": 새 판, "appVersion": 지금 도는 앱 판번}`.
- 복원 = `decodeRestartPending(raw, 지금 앱 판번)` 순수 함수 — **저장 때 판번 ≠ 지금 판번이면 무효**(= 재시작으로 새 판이 켜졌다) · 새 판 == 지금 판번이면 무효 · 판번 조회 실패면 무효(검증 못 하는 대기는 만들지 않는다 = 오늘 동작으로 후퇴) · 깨진 값 무효. 무효면 칸을 지운다.
- 고른 까닭: sessionStorage 는 같은 WebView 의 새로고침엔 남고 앱 프로세스가 바뀌면 비는 수명이 「옛 앱이 살아 있는 동안」과 같다. localStorage 는 재시작을 넘어 남아 거짓 대기의 원천이 되므로 기각. 판번 짝은 그래도 남는 경우의 2중 방어.
- 복원은 1회(지연 초기화 promise) · 메모리 값이 이미 있으면 덮지 않는다(이벤트가 복원보다 먼저 온 경합).

### 동작
- `onUpdateButton`: 대기면 `restartAfterUpdate(대기 판번)` · 아니면 종전 `checkForUpdate(false)`(캐시로 경로를 고르지 않는 규칙 유지 — 대기 판번은 「확인 결과 캐시」가 아니라 **이미 끝난 교체의 사실**).
- `checkForUpdate(silent)`: 첫 줄에서 복원 완료를 기다린 뒤 대기면 「다시 켜기」 표시만 다시 칠하고 **끝**(설치 안내 토스트·배지 덮어쓰기·설치 확인 창 0). → 시작 확인(⌘R 뒤)·6시간 주기·포커스 확인 모두 여기로 들어온다.
- `promptBinaryPatch`: install_update 직전에 대기면 재시작으로 넘긴다(확인 창이 떠 있는 사이 교체가 끝난 경합 방어 1줄).
- `restartAfterUpdate`: **진행 중 재진입 차단**(`restartingAfterUpdate` · try/finally) — 연타·알림+단추 동시 = 호출 1(4군 ①). 실패·확인 창 취소 뒤엔 풀려서 다시 누를 수 있다. 대기 상태는 건드리지 않는다.
- 표시: 단추 글자 「업데이트」→「다시 켜기」(데몬 「↻ 재시작」과 다른 이름) · 배지 「!」(경고색) · 툴팁 안내.
- 알림 문구(바뀌는 문자열): 이름 「✅ 새 앱 설치 완료」 · 본문 「새 앱 1.1.7 설치가 끝났습니다. 이 알림을 누르면 하던 대화를 저장하고 앱을 다시 켭니다. 나중에 하시려면 위쪽 「다시 켜기」 단추를 눌러 주세요.」

### 새 모듈 `ui/src/restartpending.ts`(순수) + `restartpending.test.ts`
encode/decode · 단추 동작 판정 · 문구 · 상수. main.ts 는 배선만.

## 안 하는 것(과 까닭)
- ⓐ 알림 무기한 — 오너 정책(master 불허).
- ⓓ Rust 재다운로드 방지 — 이 수리 뒤엔 UI 가 대기 중 install_update 를 부르지 않는다(c17b·c17c 로 측정). 남는 구멍 = sessionStorage 가 사라지는 드문 경우 → 오늘 동작과 같음(악화 0).
- 대기 중 「더 새 판」(대기 1.1.7 < 최신 1.1.8): 옛 프로세스에서 바로 설치하지 않고 먼저 다시 켜기 → 새 앱이 켜지며 시작 확인이 1.1.8 을 알린다. 까닭: 다시 켜기 한 번이면 풀리고(막힘 아님), 옛 프로세스에서 두 번째 교체를 허용하면 재다운로드 경로를 다시 여는 셈이다.
- 확인 창 제목 「재시작 (새 판 v…)」 등 기존 문구 — 이 수리로 바뀌지 않는 문자열(대원칙 2) → 곁 항목.
